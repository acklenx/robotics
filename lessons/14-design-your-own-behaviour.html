Lesson 14 · 60 minutes

Design Your Own Behaviour

From an idea to a program the robot can run

Today's goal

Invent a behaviour nobody has demonstrated, write it, test it, and describe how it fails.

Ideas in this lesson

  • A behaviour is a rule you can state in one sentence before you write it
  • Write the sentence first, then the blocks
  • Every behaviour has failure modes; finding yours is finishing the work
  • Testing means trying to break it, not proving it works

Sense → Think → Do

You design the whole loop this time.

How the session runs

  1. Pitch: each group writes their behaviour in one sentence on paper before touching a robot.
  2. Sketch the sense-think-do loop: what does it check, what does it decide, what does it do?
  3. Build it in blocks. Keep it under fifteen blocks — short programs fail in ways you can see.
  4. Test it. Then try to break it on purpose and write down what broke.
  5. Demo to the group: the sentence, the demo, and the failure. All three.

Try this

  • A robot that finds the darkest corner in the room and parks there.
  • A guard robot that stays still until something comes close, then chases it.
  • A robot that traces the edge of a table without falling off — which sensor tells you where the edge is?

When it goes wrong

What you seeWhat it means

Notes for the grown-up

Insisting on the sentence before the blocks is the whole lesson. Groups that start by dragging blocks build something that half-works and cannot say what it is; groups that write 'it turns away from whichever side is blocked' debug in minutes.
