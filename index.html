Robotics

Our 4WD mecanum robot drives forward, slides sideways and spins, all at the same time. We built it, wired it, and now we drive and program it from an IR remote. No phone needed.

Remote guide Every key on one printable page: drive, make a program, run it, calibrate, and the light bot. Open → Programming guide Step by step: drive, make a program of moves, save it in a slot, run it. Instructor tools at the bottom. Learn → Challenges Shapes to program from the remote. Does the robot draw the picture? Try them → Light bot Moth mode chases a flashlight, cockroach mode runs from it. Two light sensors on the front, one more on the back if you like. Shine → Wiring Every wire on the robot, and the light sensors for the light bot. Wire it → Blocks Coming up: program the robot by snapping blocks together on a computer, then send the program to the remote's slots.
