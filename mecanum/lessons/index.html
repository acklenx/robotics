Lessons

Ten stand-alone sessions for the 4WD mecanum robot, an hour each. Pick any order: each one hangs on Sense → Think → Do and uses the robot as it is (firmware mecanum_holonomic v0.10.20).

01 Robot or Not? What makes a machine a robot Decide whether something is a robot using a test you can defend, then put our mecanum robot through that same test. 02 Same Job, Different Physics Laser, sonar and infrared Measure the same distances with the laser and the sonar, predict which one will be fooled by each object, and explain why. 03 Did It Actually Turn? Open loop vs closed loop Run the same move with the IMU off and on, measure the difference, and explain what the robot 'knows' in each case. 04 Every Robot Is Different Measuring your own robot's numbers Let the IMU measure your robot's own motors, check one distance with a tape measure, and explain why one trial is not enough. 05 Sideways Is a Direction Mecanum wheels and adding arrows Predict how the robot will move from the direction of each wheel, then drive a path a normal car cannot. 06 Too Much, Too Little, Just Right Tuning the line follower Change the line follower's correction strength while it runs, find the wobble point and the drift point, and settle on a value between them. 07 Roll Call on Two Wires How the parts talk: I2C buses and addresses Draw every part on the robot's I2C bus with its address, and explain what goes wrong when two parts share one. 08 When in Doubt, Stop Designing a robot that fails safely List every way our robot stops itself, test each one, and invent one more safety rule. 09 Robots Go Wrong Debugging like an engineer Find and fix three planted faults using the robot's own messages and Watch mode, and write down how you found each one. 10 The 32 KB Backpack Engineering is choosing Choose a feature set that fits in the Arduino's memory, justify every choice, and prove it fits by compiling it.
